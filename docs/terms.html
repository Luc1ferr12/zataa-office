Zataa Topup (zataa.my.id) · berlaku sejak 12 Oktober 2026

Zataa Topup adalah aplikasi internal milik Zataa untuk mengunggah dan memantau konten di akun media sosial resmi Zataa sendiri (Instagram dan TikTok). Aplikasi ini tidak dibuka untuk pengguna umum.

Penggunaan

  • Hanya pemilik akun Zataa yang login dan memberi izin ke aplikasi ini.
  • Konten yang diunggah dibuat oleh tim Zataa dan disetujui pemilik sebelum tayang.
  • Aplikasi membaca statistik postingan Zataa sendiri (tayangan, suka, komentar, bagikan) untuk evaluasi konten.

Pencabutan izin

Izin bisa dicabut kapan saja dari pengaturan aplikasi terhubung di Instagram/TikTok. Data token dihapus dari server kami setelah izin dicabut.
