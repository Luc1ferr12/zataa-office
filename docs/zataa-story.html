Zataa Story Uploader

Internal publishing tool for the YouTube channel Zataa Story · by Zataa (zataa.my.id)

Uses YouTube API Services

Zataa Story publishes short history and archaeology mysteries as YouTube Shorts. This tool helps the channel owner produce and publish them. It is used only by the owner of the Zataa Story channel; it is not offered to the public.

How it works

  1. The Zataa team prepares a Short: script with cited sources, openly licensed images (credited in the description), narration and subtitles.
  2. The channel owner receives the finished video in a private Telegram bot and chooses Approve, Revise or Reject, and the visibility (public, unlisted or private).
  3. Only after approval, the tool uploads the video to the owner's channel with the YouTube Data API (videos.insert) at the scheduled time, using the title, description and visibility the owner approved.
  4. The tool reads the channel's own statistics (YouTube Data API and YouTube Analytics API) to send the owner a weekly performance summary.
